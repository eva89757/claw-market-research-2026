01 OVERVIEW // 产品核心定位

WHAT IS OPENCLAW?

OpenClaw 不是 AI 聊天工具，而是一个 自托管 AI Agent 网关——运行在用户自有硬件上，连接日常消息平台，成为真正属于个人的 AI 助理。

> CHANNELS // 消息平台
同时接入 WhatsApp、Telegram、Discord、Slack、Signal、iMessage、微信、飞书、Matrix、IRC 等 20+ 平台。

单 Gateway 同时服务所有渠道
> AGENT // AI 执行引擎
Pi agent runtime，支持多 Agent 路由、Workspace 隔离、上下文记忆、工具调用。内置浏览器自动化、exec、文件操作。
> SKILLS // 技能生态
ClawHub 市场，Skills API 开放，第三方可开发分发。已有日历、邮件、SEO、小红书、飞书图像等 Skills。
> NODES // 多端节点
macOS 菜单栏、iOS/Android 配对。支持语音唤醒、摄像头、屏幕录制、GPS 定位、Canvas 共享。
> MODELS // 模型中立
OpenAI、Anthropic、Google、Ollama、vLLM、SGLang 等 35+ 提供商。支持本地模型，彻底不绑定单一 AI 厂商。
> SECURITY // 数据主权
完全自托管，数据存储在用户自有设备。支持私有化部署，企业数据不出门。DM 配对 + Allowlist 安全机制。
▶
KEY INSIGHT // 关键认知 QClaw 是 OpenClaw 的商业化封装版。OpenClaw 是 MIT 协议开源项目，QClaw 在此基础上增加商业化能力。两者核心差异化建立在「自托管 + 消息集成 + 技能生态」三角上——这是大厂无法复制的护城河。
